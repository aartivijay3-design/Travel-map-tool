======================================================
 Travel Map Tool  –  Server Deployment Guide
 (Windows Server, No IT Required)
======================================================

WHAT YOU NEED
──────────────
• Admin access to the server (to run the setup script)
• The server must have internet access for the first
  setup run (to download Python + dependencies)
• The project folder copied to the server


STEP 1 — COPY PROJECT TO SERVER
─────────────────────────────────
Using your network drive, copy the entire
"travel-map-tool" folder to the server.

  Example: D:\Apps\travel-map-tool\

Keep the folder structure exactly as-is.


STEP 2 — RUN SETUP (one time only)
────────────────────────────────────
1. On the server, open the travel-map-tool folder
2. Right-click "server_setup.bat"
3. Click "Run as administrator"
4. Wait ~5 minutes for it to finish

It will automatically:
  ✓ Download and install Python 3.11
  ✓ Install all Python dependencies
  ✓ Open port 5000 in Windows Firewall
  ✓ Register the app as a Windows Service
    (starts automatically on every reboot)

At the end it prints the URL to share with your team,
something like:
  http://192.168.1.50:5000
  http://SERVERNAME:5000


STEP 3 — SHARE THE URL
────────────────────────
Send your colleagues the URL printed at the end
of setup. They open it in any browser on the
company network. No install needed on their end.


THAT'S IT. NO IT INVOLVEMENT NEEDED.


MANAGING THE SERVICE
──────────────────────
The app runs as a Windows Service called "TravelMapTool".

Easiest way to manage it:
  1. Press Win + R, type "services.msc", press Enter
  2. Find "Travel Map Tool" in the list
  3. Right-click → Start / Stop / Restart

Or via Command Prompt (as admin):
  Start:   sc start TravelMapTool
  Stop:    sc stop  TravelMapTool
  Status:  sc query TravelMapTool

Logs are at:  travel-map-tool\logs\app.log


UPDATING THE APP
─────────────────
When you receive updated files:
1. Copy the new files to the server folder
   (overwrite existing)
2. Restart the service via services.msc or:
   sc stop TravelMapTool && sc start TravelMapTool


TROUBLESHOOTING
────────────────
Can't reach the URL?
  → Make sure you're on the company network/VPN
  → Check the service is running (services.msc)
  → Check logs\app.log for errors

"Connection refused" error?
  → Service may be stopped — restart it
  → Confirm port 5000 is open:
    netsh advfirewall firewall show rule name="TravelMapTool"

Map generation fails?
  → Check logs\app.log
  → Restart the service

Service won't start after reboot?
  → Re-run server_setup.bat as administrator
